# Phishing URL Scanner

> Static, heuristic analysis of suspicious links. The link is never opened or sent anywhere.

**▶ Live demo: https://darkoes.github.io/phishing-url-scanner/**

## Features

- Lookalike domains (paypa1, rn to m), punycode and homoglyphs, the "@" trick, raw IPs, unusual ports`n- Brand abuse in subdomains and paths, URL shorteners, high-abuse TLDs, pressure keywords, executable downloads`n- Risk score, verdict and a URL anatomy view that highlights the registrable domain

## Notes

Heuristics can be wrong. A low score is not a guarantee that a link is safe.

## Tech

Single `index.html` file. Vanilla HTML, CSS and JavaScript, no dependencies, no build step. Hosted on GitHub Pages.

Run locally: open `index.html` in a browser.
